## Name

**Tech Reel Scriptwriter: Fact-Checked 30-Second Scripts**

- Skill folder and `name:` stay `tech-reel-script-writer` (renaming the folder changes how agents load it).
- "Tech" and "Fact-Checked" set it apart from the free, general-purpose "Reel Script Writer" skills
  already listed on skill registries.

Alternatives:
- **Dev Reels Scriptwriter: Verified Short-Form Scripts**
- **ReelCheck for Developers.** Shorter and brandable, but "ReelCheck" was an older broadcast
  quality-control product (Cel-Soft), so check trademarks before using it.

## Tagline (one line)

Accurate 25-30 second Reels, Shorts and TikTok scripts about code, fact-checked and length-checked
before you record.

## Short description

Turns one technical topic (DSA, system design, AI/ML, dev tools, OS, tech interviews) into a tight
vertical-video script: hook options, a voice-over block, a shot list, a cheat sheet and a caption with
hashtags for Instagram, YouTube Shorts or TikTok. Every claim is listed with how it was verified, and a
bundled checker enforces word counts and on-screen limits. Includes fix mode for your own drafts, batch
planning and Hinglish narration support.
