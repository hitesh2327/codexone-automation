## 1. Audit Summary: Why Non-Tech & Custom-Niche Creators Fail Today

Although [`taste-cadence.tsx`](file:///d:/Code/codexone-automation/web/src/components/config/taste-cadence.tsx#L43-L103) presents 30+ niches across 5 groups (*Tech & Dev*, *Food & Lifestyle*, *Education & Knowledge*, *Entertainment*, *Business & Finance*) plus free-text custom niches and AI-suggested categories, the backend topic fetching, classification, ranking, and persistence pipeline remains structurally coupled to Mintly's original 6 software engineering pillars (`AI`, `SystemDesign`, `DSA`, `Interview`, `OS`, `Dev`).

## 2. User Stories

- **US-1 (Non-Tech Creator Onboarding):** *As a Personal Finance creator, when I select "Personal Finance & Investing" and click "AI Suggest", I want Mintly to generate 4–6 finance pillars (e.g., Tax Hacks, Index Funds, Debt Traps) with descriptions, weights, and curated finance feeds so my daily posts never contain HackerNews or arXiv AI papers.*
- **US-2 (Custom Niche & Weight Control):** *As a Fitness coach, I want to set pillar weights (`50% Hypertrophy`, `30% Meal Prep`, `20% Myth Busting`) and attach per-pillar tone hints so Mintly rotates posts proportionally instead of picking equally or sticking to one category.*
- **US-3 (Custom RSS / Substack / Subreddit Sources):** *As a B2B SaaS marketer, I want to add my favorite Substack newsletter URL and 2 subreddits, click "Test Feed", and immediately see the top 3 parsed headlines—with malformed or internal URLs safely blocked.*
- **US-4 (Multi-Tenant Isolation):** *As any Mintly creator, I want my topic deduplication history (`posted_topics`), custom categories, and feed sources strictly isolated to my account so another creator's posts never block my topic queue.*
- **US-5 (Rich/Unicode Category Names):** *As an international or niche creator, I want to name categories with symbols or Unicode (e.g., `Café Menu`, `Tax & GST (India)`, `UI/UX Critiques`) and generate posts on demand without validation or database errors.*

## 3. Edge Cases & Security Guardrails

| # | Edge Case | Expected System Behavior |
|---|---|---|
| **EC-1** | **User has 0 active categories** (deleted all chips or skipped onboarding) | `PUT /api/categories` requires `>= 1` active category (inline error if attempting to remove the last one). If DB legacy row has `[]`, pipeline auto-provisions niche-matched default pillars (never `DSA`/`SystemDesign` for non-tech niches) or surfaces clear UI prompt on `/generate`. |
| **EC-2** | **Unlisted custom niche** (e.g., `"Urban Beekeeping"`, `"Ceramic Pottery"`) not in `NICHE_REDDIT_MAP` | **Do NOT fall back to tech `REDDIT_SUBS`.** Query Google News topic RSS (`https://news.google.com/rss/search?q=<encoded_niche>`) + Gemini evergreen topic generation anchored to the user's `user_categories` descriptions. |
| **EC-3** | **All category weights set to 0 or deactivated except 1** | Validation enforces at least 1 active category with `weight >= 1` (sum > 0). If only 1 category is active, `pick_category()` skips `avoid == only_category` check gracefully without crashing. |
| **EC-4** | **0 trending candidates match the picked category** | Do NOT dump into `cats[0]`. Pass top 40 normalized niche candidates to Gemini in `rank_topics.py`; if none genuinely match `{category.name}: {category.description}`, Gemini generates a fresh `evergreen=true` topic for that category. |
| **EC-5** | **SSRF attack via Custom RSS/Substack URL** (`http://127.0.0.1`, `http://169.254.169.254/latest/meta-data`, `https://10.0.0.5/feed`, DNS rebinding / HTTP 302 redirect to localhost, or 50 MB XML bomb) | Enforce `https://` only; resolve DNS and block loopback/private/link-local/CGNAT/ULA IPs before connecting; disable or re-validate every redirect hop; cap response download at **1 MB**; parse XML with `defusedxml` (or entity-expansion disabled) and 10s timeout. |
| **EC-6** | **Broken / 404 / Non-RSS user feed URL** | Record `last_error` on `user_topic_sources` row, never crash `fetch_all()` for remaining sources, and show actionable status badge in UI (*"Could not read feed — check URL or try another source"*). |
| **EC-7** | **Cross-tenant topic collision** | Tenant A (`user_id=10`) publishes *"Why Protein Timing Is Overrated"*. Tenant B (`user_id=11`) with the same Fitness niche MUST still be eligible to fetch, rank, and publish that topic. |
| **EC-8** | **Long / Unicode category names** (up to 64 chars, e.g., `"S&P 500 & Tax-Loss Harvesting (US)"`, `"Café & Pastry"`) | `String(64)` across `user_categories`, `posts`, `posted_topics`, `generation_jobs`; `GenerateBody.category` accepts Unicode word characters + spaces + `&/_-():'+` up to 64 chars; slugification handles non-ASCII safely. |
| **EC-9** | **Legacy users migrating from `User.taste.categories`** | First read / migration script auto-backfills existing `User.taste["categories"]` into `user_categories` with default equal weight `20`, preserving existing behavior with zero downtime. |
