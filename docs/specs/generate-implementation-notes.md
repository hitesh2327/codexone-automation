## Decisions / deviations

- **Concurrency (R1)**: option (a) — Generate has its own group `generate-posts`; poll/refresh keep `queue-state`. The DB is the lock for queue state in production (Postgres). File mode keeps the rebase-before-push step.
- **Tomorrow's slots (R9)**: shown on the board, not requestable (MVP: today's slots + Next free).
- **OQ3 warning near scheduled triggers**: not implemented (no FR); cron-job.org times live outside the repo.
- **Config readiness endpoint**: not called (doesn't exist yet); `dispatch_configured` covers E1.
- Logs' source dropdown list is owned by the Logs page; `generate` appears there via facets once events exist.
